# Security policy

## Supported version

Security fixes target the latest version on the default branch.

## Reporting a vulnerability

Do not open a public issue containing bank details, client records, generated invoices, or an exploit. Use [GitHub private vulnerability reporting](https://github.com/gleero/codex-invoice-generator/security/advisories/new).

The project stores sensitive data only in the user's workspace and excludes it from Git by default. Currency research must never include account or bank data in a web query.
